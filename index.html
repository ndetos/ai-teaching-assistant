🚀 One Command to Install

Copy and paste this command into your terminal. Everything else is automatic.

curl -fsSL https://raw.githubusercontent.com/ndetos/ai-teaching-assistant/master/install.sh | bash
✅ Copied! Paste it in your terminal.

🗑️ One Command to Uninstall

Remove everything — including the AI model and container images.

🐧

Linux / macOS / WSL

curl -fsSL https://raw.githubusercontent.com/ndetos/ai-teaching-assistant/master/uninstall.sh | bash
✅ Copied!

⚠️ Will ask if you want to remove Docker too

🪟

Windows (CMD / PowerShell)

curl.exe -fsSL -o uninstall.bat https://raw.githubusercontent.com/ndetos/ai-teaching-assistant/master/uninstall.bat && uninstall.bat
✅ Copied!

⚠️ Will ask if you want to remove Docker too

📋 What gets removed: Containers, Docker images, volumes, networks, and all AI Tutor files.
Docker itself is kept unless you choose to remove it during uninstall.

💻 How to run the command:

🐧 Linux
  1. Open Terminal (Ctrl+Alt+T)
  2. Paste the command and press Enter
🍎 macOS
  1. Open Terminal from Launchpad
  2. Paste the command and press Enter
🪟 Windows
  1. Press Win + R, type cmd, and press Enter
  2. Right-click in the black window and select "Paste"
  3. Press Enter to run the command
